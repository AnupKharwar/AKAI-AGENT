Agent Loop : What Is an Agent Loop?
An Agent Loop is a repetitive cycle in which the Al agent:
1. Thinks about the current situation.
2. Decides the next action.
3. Executes that action.
4. Observes the result.
5. Decides whether another action is required.
The loop continues until the goal has been achieved.

The Agent State is simply a dictionary containing everything the agent needs while solving the current task.
Field        : Description
user_request : Original user query
current_step : Current iteration number
max_steps    : Maximum iterations allowed
actions      : List of actions already executed
observations : Results returned by those actions
finished     : Indicates whether execution has completed
final_answer : Final response returned to the user
